resources/images/
  logo.png     - placeholder for the app logo (not included; add your own)
  icons/       - placeholder folder for toolbar/menu icons

These are optional. The application runs fine without any images here;
LoginFrame, dashboards, etc. use plain text/Swing components only, so
nothing will break if this folder stays empty. Add images here and wire
them up with ImageIcon(...) in the UI classes if you want a polished look.
